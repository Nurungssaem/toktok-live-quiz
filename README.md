# 톡톡 라이브 퀴즈 🎯

문제 사전 등록 없이 **교사가 수업 중 입력하는 글을 즉시 학생에게 보여주는** 실시간 객관식 퀴즈입니다. 앱 설치·회원가입 없이 교사는 방을 만들고, 학생은 **6자리 코드와 이름**으로 참여합니다.

## 바로 실행하기 (Windows)

1. [Python 공식 사이트](https://www.python.org/downloads/)에서 Python 3.10 이상을 설치합니다. 설치 시 **Add Python to PATH**를 선택하세요. 이미 Python이 설치되어 있다면 건너뜁니다.
2. ZIP 파일 압축을 풀고, `app.py`가 들어 있는 폴더를 엽니다.
3. 압축을 푼 폴더 안의 **`서버시작.bat` 파일을 더블클릭**합니다. 안 되면 해당 폴더 주소창에 `cmd`를 입력해 명령 프롬프트를 연 다음 다음 명령을 입력합니다.

   ```bat
   py app.py
   ```

   `py`가 안 되면 `python app.py`를 실행합니다. **별도의 패키지 설치는 필요 없습니다.**
4. 교사 컴퓨터에서 `http://localhost:8787`에 접속합니다. **새 퀴즈방 만들기** → 6자리 코드 확인 → 학생들에게 코드를 안내합니다.
5. 학생들이 **같은 와이파이/학교 네트워크**에 연결돼 있다면, 서버 시작 화면에 나오는 `http://192.168.x.x:8787` 형식의 **같은 주소**를 학생 기기에서 엽니다. 교사 컴퓨터의 `localhost` 주소를 학생에게 알려주면 접속되지 않습니다.

> 처음 실행할 때 Windows 방화벽 안내가 나오면 학교/개인 사설 네트워크에서 Python의 연결을 허용해야 할 수 있습니다. 학교 네트워크에서 기기 간 직접 통신이 차단됐다면 외부 서버에 배포해야 합니다.

## 사용법

- **교사:** 새 방 생성 → 학생 입장 → 문제/보기 작성 → 교사만 보이는 라디오 버튼으로 정답 선택 → **점수 배수 선택(1·2·3배 / 소수점 직접 입력)** → **퀴즈 시작** → **퀴즈 종료 · 순위 공개** → **다음 문제 만들기**. 다음 문제에도 기존 점수가 누적됩니다.
- **학생:** 참여 주소 접속 → 방 코드(6자리) 및 이름/별명 입력 → 교사 입력 내용을 실시간 확인 → 퀴즈 시작 후 보기 하나 선택 → 종료 후 정답과 점수/순위 확인.
- 교사 화면의 **학생 링크 복사**를 사용하면 학생이 6자리 코드를 직접 치지 않아도 입력 칸에 코드가 채워집니다(이름은 직접 입력).
- 새로고침해도 **같은 브라우저**에서는 입장 정보가 유지됩니다.

## 점수 규칙

- 정답: **(1,000점 + 속도 보너스 최대 500점) × 이번 문제의 배수**. 기본은 1배이며 교사는 1배, 2배, 3배 버튼 또는 직접 입력으로 **0.01~100배(소수점 둘째 자리까지)**를 지정할 수 있습니다. 예를 들어 원래 1,300점을 받을 학생은 1.5배 문제에서 1,950점을 받습니다. 소수점 계산 결과는 가장 가까운 정수로 반올림합니다.
- **배수는 문제마다 독립적으로 설정**하며, 다음 문제는 다시 1배로 초기화됩니다. 학생도 현재 문제의 배수를 볼 수 있고 교사는 문제 시작 후 배수를 변경할 수 없습니다.
- 원래 점수의 속도 보너스는 퀴즈 시작부터 최대 500점으로 출발합니다. 퀴즈 시작과 동시에 보너스가 500점에서 출발해 30초 동안 감소하고 이후에는 기본 1,000점을 받습니다.
- 오답/미응답: 기본 **0점**.
- 각 문제는 **한 번만** 제출합니다. 서버에 도착한 시간을 기준으로 채점하므로 기기/네트워크 속도에 소폭 영향을 받을 수 있습니다.
- 학생 **최종 점수의 동점을 방지**하기 위해 결과 발표 시 필요할 경우 **작은 보정 점수(대략 학생 수 이내)**를 추가합니다. 동일한 점수라면 정답 수, 빠른 총 응답 시간, 입장 순서를 활용합니다. 따라서 오답/미응답 학생에게도 순위 구분용 보정 점수가 소량 부여될 수 있습니다.

## 중요 안내

- **실시간 연결:** 서버에서 Server-Sent Events(SSE)를 사용하므로 교사가 타이핑하는 문제/보기가 보통 수백 밀리초 내에 학생 기기에 반영됩니다. 모든 학생에게 동일한 서버의 주소를 알려야 합니다.
- **정답 비공개:** 교사가 선택한 정답 인덱스는 준비/진행 중 학생 API 응답에 포함하지 않습니다. 퀴즈 도중에는 획득한 점수도 학생에게 공개하지 않아 정답 여부가 드러나지 않습니다. 교사가 종료 버튼을 누르면 학생들에게 공개합니다.
- **방 보관:** 방, 학생, 점수는 서버 메모리에 저장됩니다. `Ctrl+C`로 종료하거나 서버가 재시작되면 사라집니다. 장시간 운영하거나 서버 재시작 후 복구해야 한다면 DB 연동이 필요합니다.
- **연결 인원:** 기본 방당 최대 80명. 일반적인 한 학급 규모를 가정했습니다.
- **개인정보:** 회원가입/메일/전화번호 입력 없이 참여할 수 있습니다. 학교에서 사용할 때 실명 대신 별명을 권장합니다.
- **보안:** 교사 권한은 무작위 비밀 토큰으로 보호되며, 학생에게 전달되는 공유 링크에는 포함되지 않습니다. 학교 밖 인터넷 배포 시 HTTPS를 사용하세요.

## 인터넷 주소로 사용하기 (GitHub + Render 무료 웹 배포)

**학생이 각자 다른 기기·다른 네트워크에서도 접속하는 웹주소가 필요하면, 공개 웹서버에 배포해야 합니다.** 이 프로젝트에는 Render 무료 웹서비스용 `render.yaml`과 `Dockerfile`이 들어 있습니다.

처음 배포하는 분은 압축파일의 **`웹사이트_배포_방법.txt`**를 열어 순서대로 따라하세요. 요약하면 다음과 같습니다.

1. GitHub의 새 저장소를 만들고 이 프로젝트의 **폴더 안에 있는 파일과 `static` 폴더**를 업로드합니다. (ZIP 파일 자체를 업로드하면 안 됩니다.)
2. [Render 대시보드](https://dashboard.render.com/)의 **New → Web Service**에서 해당 저장소를 연결합니다.
3. **Language/Runtime: Docker, Plan: Free, Root Directory: 빈칸**으로 선택하고 배포합니다. `Dockerfile`이 서버를 자동으로 실행하며, Render가 설정하는 `PORT` 환경 변수를 사용합니다.
4. 발급받은 `https://...onrender.com` 주소를 교사와 학생 모두 접속합니다.

> **무료 웹서비스 주의사항:** Render 무료 요금제는 약 15분 동안 외부 요청이 없으면 잠들 수 있고 첫 접속 시 약 1분 정도 걸릴 수 있습니다. 이 앱은 방/학생/점수를 서버 메모리에 저장하므로 무료 인스턴스가 잠들거나 재시작/재배포되면 모든 데이터가 초기화됩니다. 수업 직전 방을 생성하고, 수업 중 중요한 점수를 별도 기록하세요. 장기적인 수업 이력 저장은 데이터베이스 연결이 필요합니다.

## 파일 구성

- `app.py` : 웹서버, 방 관리, 점수 계산, 실시간 메시지
- `static/index.html` : 교사/학생 화면
- `static/styles.css` : 반응형 디자인
- `static/client.js` : 퀴즈 입력·진행·상태 동기화
- `tests/test_app.py` : 자동 동작 테스트
- `서버시작.bat` : Windows에서 더블클릭해 서버 시작
- `Dockerfile`, `render.yaml` : Render 무료 웹배포를 위한 설정
- `웹사이트_배포_방법.txt` : GitHub/Render 초보자용 단계별 배포 안내

※ Python 3.10 이상 / Chrome, Edge, Safari 등 최신 브라우저를 권장합니다.
